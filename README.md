## 作品简介

一栋等着交班的楼，一本会自己改字的册子，二十三点以后，有人敲门。

玩家扮演老式大厦的夜班值班员，入职后拿到一份《夜班守则》——共十二条。守则条文会在深夜自行篡改，措辞与记忆里的版本逐渐不一致。玩家必须逐条判断规则真伪、在异常事件中做出抉择，走向不同结局。

作品侧重心理悬疑与信息甄别，核心不是"选对选项"，而是"判断哪条规则还值得相信"。

## 核心玩法

- **规则公示开局**：正式进入值班室前，先完整阅读十条守则，建立初始认知
- **规则动态篡改**：守则条文随剧情推进自行改写、新增、变红，制造信息冲突
- **分支选择叙事**：关键节点多选项，不同判断走向不同结局（含死亡结局）
- **存档读档**：支持从头开始或继续上次进度
- **规则回顾**：随时调出当前版本守则，对照冲突
- **值班日志**：记录已发生事件与判断结果，可回溯自己走过哪一步
- **环境音与沉浸 UI**：暗调走廊视觉、灯管闪烁、夜间氛围音，建议佩戴耳机

## 技术实现

- 纯前端网页项目：HTML + CSS + JavaScript
- 无后端、无数据库，全部逻辑在浏览器本地完成，打开即运行
- 分支剧情数据本地存储，存档基于浏览器 localStorage
- 适配桌面与手机浏览

## 开发方式

本项目为 AI 辅助开发实践：使用 AI 建站工具完成需求拆解、页面生成、剧情逻辑搭建与反复迭代，人工负责世界观设计、规则文本创作、剧情分支编排与体验调优。属于「人负责创意与判断，AI 负责实现」的典型 AIGC 应用开发流程。
